# Nvslimmer-1.0.6
NVSlimmer 1.0.6 — Unofficial Archive

Unofficial archive/mirror of NVSlimmer Continued 1.0.6, a utility for creating customized and minimal NVIDIA driver installation packages.

NVSlimmer allows users to remove optional NVIDIA driver components and build a smaller installation package containing only the features they need.

Project origin

The original NVSlimmer was developed by uKER.

Development of the original project stopped after the older NVSlimmer releases. This repository contains a later NVSlimmer Continued build.

I am not the developer of NVSlimmer or NVSlimmer Continued and I do not claim ownership of their source code or binaries.

Features

Customize NVIDIA driver packages

Remove optional NVIDIA components

Reduce driver package size

Repackage a customized NVIDIA driver

Select only the components you need

Support newer NVIDIA package layouts compared with the original NVSlimmer releases

Important

NVSlimmer modifies the contents of an NVIDIA driver installation package.

It does not modify NVIDIA's actual display-driver code and it does not guarantee increased FPS or reduced latency.

Keep an untouched copy of the official NVIDIA driver installer before creating a customized package.

Laptop users should be especially careful when removing Optimus, Hybrid Graphics, audio, USB-C or other hardware-specific components.
